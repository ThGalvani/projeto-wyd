# Sistema RedDragon - Documentação Completa

## 📊 Visão Geral

O **Sistema RedDragon** é um tier intermediário de equipamentos endgame posicionado entre **Destruição (Arch)** e **Draconian**, oferecendo progressão natural para jogadores Celestial 380+.

### Hierarquia de Equipamentos
```
Corvo (ItemLevel 5)
    ↓
Destruição/Arch (ItemLevel 6)
    ↓
🔥 RedDragon (ItemLevel 7) ← NOVO
    ↓
Draconian (ItemLevel 8+)
    ↓
Bahamut (Future)
```

---

### Requisitos para Equipar

- Item Destruição +15 da mesma peça

- Infernal Flame (craft ou drop)
- 150.000.000 gold

## 🐉 Boss: RedDragon Ignis

### Informações Básicas
- **Nome**: RedDragon Ignis
- **HP**: 500.000.000 (500M)
- **Level**: 450
- **Localização**: Vulcão Carmesim (nova área ou reutilizar mapa)
- **Spawn**: A cada 6 horas (04:00, 10:00, 16:00, 22:00 GMT-3)
- **Dificuldade**: Requer grupo de 10-15 jogadores bem equipados

### Mecânicas do Boss

#### Fase 1 (100%-70% HP): **Fúria Flamejante**
- **Dragon Breath**: Cone frontal 8m, 50k dano de fogo
- **Tail Sweep**: AoE circular 5m, knockback + 30k dano
- **Flame Pool**: Deixa poças de fogo no chão (5k/seg)

#### Fase 2 (70%-40% HP): **Escamas Endurecidas**
- Ganha buff: +50% Defesa
- **Meteor Shower**: Random AoE em 5 jogadores, 40k dano cada
- **Wing Gust**: Empurra todos os jogadores para trás
- **Enrage**: Se não quebrar escamas em 3min, wipe do grupo

#### Fase 3 (40%-0% HP): **Inferno Apocalíptico**
- Remove buff de defesa, ganha +100% velocidade de ataque
- **Infernal Nova**: AoE global, 60k dano (requer escudo de healer)
- **Summon Dragonlings**: 3 adds com 5M HP cada
- **Berserk**: Aos 8 minutos de combate, dano aumenta 500%

## 🔥 Sistema de Composição: **Dragon Infusion**

### Conceito Inovador
Diferente dos sistemas tradicionais de "combine" que simplesmente juntam itens, o **Dragon Infusion** permite que o jogador **escolha adicionais** através de um sistema de **Essências Elementais**.

### Como Funciona

#### Passo 1: Preparação Base
Reunir materiais base:
- Item Destruição +15 (qualquer adicional)
- 3x RedDragon Scale
- 1x Dragon Soul
- 2x Infernal Flame
- 150M gold

#### Passo 2: Escolha da Essência (INOVAÇÃO)
Jogador escolhe **1 Essência Elemental** que define o adicional extra:

| Essência | Como Obter | Adicional Garantido (Armas) | Adicional Garantido (Armaduras) |
|----------|------------|------------------------------|----------------------------------|
| **Essência do Fogo** | Boss Ignis (30%) | +72 Dano Físico | +5% Taxa de Crítico |
| **Essência do Gelo** | Boss IceQueen (30%) | +56% Ataque Mágico | +100 Defesa |
| **Essência do Trovão** | Boss Thunder Drake (30%) | +35 Penetração | +80 HP |
| **Essência da Terra** | Boss Stone Golem (30%) | +40 Absorção | +15% Redução de Dano |
| **Essência do Vento** | Quest Line (1x/char) | +8% Velocidade de Ataque | +3 Velocidade de Movimento |

#### Passo 3: Infusion no NPC
**NPC**: Mestre da Forja Dracônica (localizado em Armia, próximo ao banco)

**Interface do NPC**:
```
┌─────────────────────────────────────────┐
│   🔥 Dragon Infusion System 🔥          │
├─────────────────────────────────────────┤
│ Slot 1: [Item Destruição +15]          │
│ Slot 2: [RedDragon Scale] x3           │
│ Slot 3: [Dragon Soul]                  │
│ Slot 4: [Infernal Flame] x2            │
│ Slot 5: [Essência Elemental]           │
│ Custo: 150.000.000 Gold                │
├─────────────────────────────────────────┤
│ Taxa de Sucesso: 65%                   │
│ Em caso de falha:                      │
│ - Item Destruição retorna (perde +)   │
│ - Materiais são consumidos            │
│                                        │
│         [🔥 INFUNDIR 🔥]                │
└─────────────────────────────────────────┘
```

#### Passo 4: Resultado
**Sucesso (65%)**:
- Item RedDragon +0 com adicional base do Destruição
- Adicional da Essência GARANTIDO
- Refinação volta para +0

**Falha (35%)**:
- Item Destruição retorna em +0 (perde refinação)
- Todos os materiais são consumidos
- Gold é perdido

### Sistema de "Awakening" Progressivo (INOVAÇÃO #2)

Após criar o item RedDragon, jogador pode fazer **Awakening** para desbloquear slots de adicionais extras:

#### Awakening Stage 1 (+10 → +12)
- **Custo**: 5x RedDragon Scale + 50M gold
- **Benefit**: Desbloqueia 2º slot de adicional
- **Taxa**: 40%
- **Falha**: Perde 1 nível de refinação

#### Awakening Stage 2 (+12 → +15)
- **Custo**: 10x RedDragon Scale + 1x Dragon Heart + 100M gold
- **Benefit**: Desbloqueia 3º slot de adicional + Glow visual
- **Taxa**: 25%
- **Falha**: Volta para +10

#### Awakening Stage 3 (+15 → +15★)
- **Custo**: 20x RedDragon Scale + 3x Dragon Heart + 1x Essence of Eternity
- **Benefit**: Slot de SET BONUS (explicado abaixo)
- **Taxa**: 15%
- **Falha**: Item permanece +15 (não perde)

**Estrutura do ItemList.bin**:
```

Onde:
- 170 = Mesh ID (modelo 3D)
- 232 = Texture ID (textura aplicada)
- 1 = GlowEffect ativado (para +15★)
- 1 = TrailEffect ativado
```

## 📈 Economia e Balanceamento

### Tempo Estimado para Full Set

Assumindo 1 jogador solo:
- **Boss kills necessários**: ~15-20 (considerando RNG de drops)
- **Tempo por boss**: 6h respawn + 15-30min kill = ~6,5h
- **Total de farming**: 90-130 horas
- **Gold necessário**: ~1,2B (150M x 8 peças)
- **Itens Destruição +15**: 8 peças (custo adicional de refinação)

**Com grupo fixo**: Pode reduzir para 60-80 horas de farming ativo.

### Impacto no Power Creep

RedDragon oferece **~30% mais poder** que Destruição, mas:
- Custo exponencialmente maior (1,2B+ vs 300M)
- Requer coordenação de guild (boss group)
- Awakening system adiciona sink de tempo/gold
- Não trivializa conteúdo Draconian (ainda +15% mais forte)
